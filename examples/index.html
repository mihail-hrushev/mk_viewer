mk-viewer examples

Each example is a plain HTML page plus one TypeScript file that uses only the public API.

  • quickstart: the minimal scene, about 30 lines.
  • dynamic: meshes created, moved, recoloured and removed every frame.
  • stress: millions of instanced meshes plus unique meshes, live stats and a benchmark (try 3M + 100k).
  • models: load several glTF / GLB / OBJ files (federation), per-model show / hide / isolate / fit / unload.
  • interaction: selection events, isolate and ghosting, colour overrides, section planes, fit to selection.
  • custom-loader: a ~60-line loader plugin for a made-up format.
  • dist-usage/esm and dist-usage/umd: the built library without a bundler (run npm run build first).

Controls: left drag / one finger orbits; right or middle drag, shift+drag or two fingers pan; wheel / pinch zooms; click / tap selects (ctrl/shift-click toggles); double click / double tap sets the orbit centre.
